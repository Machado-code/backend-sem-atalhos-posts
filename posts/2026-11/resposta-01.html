Resposta: B) 2

O Where não filtra na hora. Ele guarda a regra e espera alguém pedir o resultado.

var numeros = new List<int> { 1, 2, 3 }; var pares = numeros.Where(n => n % 2 == 0); ↑ ainda não filtrou nada numeros.Add(4); Console.WriteLine(pares.Count()); ↑ filtra só agora: { 2, 4 }

No EF Core é igual: enumerar a mesma consulta duas vezes são duas idas ao banco.

Vai usar o resultado mais de uma vez? Chame .ToList() logo depois do Where.
