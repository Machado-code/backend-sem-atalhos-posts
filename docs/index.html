O problema

Aceitar a sugestão da IA é fácil. O difícil é quando ela quebra em produção, quando a consulta fica lenta ou quando o entrevistador pede para você resolver sem ajuda.

A IA erra com confiança, e só percebe o erro quem conhece o básico. Se você já copiou código sem saber por que funcionava, este material é para você.

Como funciona

Cada guia segue a mesma ordem: explicação curta, exemplo em código, atividade prática e checklist. A regra de ouro é estudar com a IA desligada, consultando só a documentação oficial, como os devs faziam antes.

No total, são cerca de 26 a 33 horas de prática. Os guias são independentes, mas o plano de 4 semanas dá a ordem mais natural.
